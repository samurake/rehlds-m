This release modernizes the launcher while retaining the 32-bit engine/plugin ABI.

- Correct frame pacing with absolute deadlines that include engine work.
- Bounded console queues, cancellable completion and explicit shutdown ordering.
- Fix EOF CPU spinning, partial-escape shutdown hangs and literal-brace crashes.
- Add frame-time statistics through `-framestats` and the launcher command `rehldsm_stats`.
- Keep console logging available when optional file logging fails.
- Use C++20 with pinned fmt 11.2.0, spdlog 1.17.0 and GoogleTest 1.18.0.
- Add standalone `--version` output with source revision, Linux sanitizer checks,
  and verified Linux/Windows release packaging.

## RC2 runtime packaging

- Remove RC1's accidental **GLIBC_2.35** requirement. Linux releases enforce a
  **GLIBC_2.34** symbol ceiling for the launcher and every bundled runtime.
- Keep GCC 11's C++ library and bundle AlmaLinux 8's maintained, ABI-compatible
  unwinder. Its 141 exported versioned symbols match the inspected GCC 11 unwinder;
  it does not import `_dl_find_object@GLIBC_2.35`.
- Run the release regression suite against the extracted archive on a frozen
  glibc 2.34 baseline without the 2.35 backport, before publishing.
- Include all launcher C++ runtime libraries, dependency manifests, package
  provenance, license notices and checksums in every release. Reject unexpected
  dependencies instead of silently shipping incomplete archives.
- Include `check-host.sh` for Linux preflight. It verifies checksums and loads the
  launcher with immediate symbol binding, without starting the engine.
- Bundle the x86 Visual C++ Release CRT DLLs beside the Windows launcher.

Linux still requires the host's **32-bit glibc >= 2.34**, `/lib/ld-linux.so.2`,
and an SSE4.2 CPU. Glibc and its matching loader are OS components, not extra
FTP files. They are intentionally not replaced or bundled. Windows requires
Windows 10/Server 2016 or later with its Universal CRT and system DLLs.

The launcher has passed local regression/sanitizer tests and an isolated ZP
fixture with five map changes. Real-player load and the hosting provider's
live runtime compatibility remain unqualified. Candidate tags are intended for
testing; these downloads do not include the engine, game DLL, AMXX or plugins.

Back up the existing executable and runtimes before replacing them. The archive's
`build-info.json` identifies its exact source commit; checksum files cover both
archive contents and the downloadable archive.
